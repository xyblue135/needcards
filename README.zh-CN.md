# 用手机说话

基于 [Aucards](https://github.com/vadimerenkov/Aucards) 的中文预设分支。

**场景**：拔智齿、口腔手术、嗓子术后等短期说不了话，但手能打字的时候。
打开应用就有 34 张写好的中文卡片，点一下就全屏显示并朗读，不用从零开始建。

原版是给自闭症 / ADHD 人群做辅助沟通用的，功能完全够，但首次打开是空列表，
而且没有中文界面。这个分支做了这些事：

1. 内置 34 张中文预设卡片，覆盖「先说一句 / 疼与求助 / 医护 / 日常需求 / 客套 / 应付外人」六类
2. 补全简体中文界面（原版只有英、俄、乌、格、波、葡、法、西八种）
3. 换 `applicationId` 和名称，可与原版同时安装
4. 底部导航中间加了「说一句」页：临时要讲的话直接打字，立刻全屏朗读，不用先建卡
5. 加了「拔牙恢复」页：从拔牙那天开始算第几天，按天给护理建议

## 底部三页

| 位置 | 页面 | 干什么 |
|---|---|---|
| 左 | 常用语 | 所有卡片，按分组筛选，右下角 + 新建，左下角菜单里管理分组 |
| 中 | 说一句 | 临时想说的话，打字 → 全屏朗读，不建卡 |
| 右 | 拔牙恢复 | 术后第几天 + 当天该注意的事 |

**常用语**：顶部一行分组标签（全部 / 收藏 / 各分组），点一下就只看那一组；
末尾的「+」直接新建分组，不用翻菜单。新建卡片在编辑页里选分组。

## 说一句

预置卡片覆盖不了所有情况。想说一句没写进卡里的话时，不用去建卡：

- 点底部中间「说一句」，键盘自动弹出，打完点「说出来」或按键盘发送
- 立刻全屏大字 + 朗读
- 这一屏不落库，退出就没了；想留就点右下角「存为卡片」
- 左下角喇叭可以再念一遍

## 拔牙恢复

底部导航第三页。第一次进去点「选择拔牙日期」，选手术那天（当天算第 1 天），
之后每次打开就能看到「第 N 天」和这一天该注意什么。

| 天数 | 阶段 | 大致要做的事 |
|---|---|---|
| 第 1 天 | 手术当天 | 棉球咬 30-40 分钟、不漱口不用吸管、间断冰敷 |
| 第 2-3 天 | 肿起来 | 48-72 小时是肿胀高峰、按时吃药、之后改温热敷 |
| 第 4-6 天 | 消肿期 | 可以正常刷牙但避开创口、忌辣忌烫忌硬 |
| 第 7 天 | 复诊拆线 | 让医生看一眼创口，可吸收线不用拆 |
| 第 8-14 天 | 基本恢复 | 饮食慢慢放开，吃完漱口 |
| 第 15 天以后 | 长肉期 | 牙槽窝 1-3 个月才填平，别去抠 |

另有一张「冷敷 / 热敷计时」卡：敷 20 分钟、停 20 分钟交替，到点响一声。
前 48 小时显示冷敷，第 3 天起自动换成热敷。应用被系统杀掉就不会响，所以卡里
留了「用系统计时器」的入口。

页面下半部可以点开任意阶段看完整清单。另有一张红色卡片列了需要马上联系医生的情况
（出血不止、第 4 天后反而加重、发烧、吞咽困难、干槽症异味）。

内容是一般性术后护理常识，**不是诊断建议，以你的医生嘱咐为准**。
日期存在 DataStore 里，随时点「改日期」重设。

## 预设内容

| 分类 | 张数 | 例子 |
|---|---|---|
| 先说一句 | 3 | 我说不了话 / 我听得见 / 请等一下 |
| 疼与求助 | 7 | 很疼 / 疼得受不了 / 还在出血 |
| 医护 | 7 | 帮我叫医生 / 几号拆线 / 什么时候复诊 |
| 日常需求 | 9 | 想喝水 / 给我冰袋 / 扶我一下 |
| 客套 | 4 | 谢谢 / 等一下 / 我没事 |
| 应付外人 | 4 | 说不了话 / 多少钱 / 放门口就行 |

卡片按用途配色：红=疼、橙=医护、蓝=日常、绿=客套、灰=对外人、紫=开场说明。
疼的时候按颜色找，不用读字。

另有 8 张预置为收藏（常用语页顶部点「收藏」标签）：我说不了话 / 很疼 / 帮我叫医生 /
想喝水 / 给我冰袋 / 帮我拿药 / 谢谢 / 等一下。手机上一屏放得下，不用滚动。

预设只在首次启动写入一次，之后随便改随便删，不会覆盖。

## 安装

- 应用名：用手机说话
- 包名：`icu.xyblue135.needcards`
- 最低 Android 8.0（API 26）

APK 见 Releases，或本地自行编译：

```bash
export ANDROID_HOME=/path/to/Android/Sdk
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

编译环境：Gradle 9.7.1 + AGP 9.4.1 + JDK 17，compileSdk 37。

## 首次使用建议

1. 打开就停在「常用语」，点顶部「收藏」标签，那 8 张是最常用的，先记住这一页
2. 临时想说的话点底部中间「说一句」，打完退出即可，不建卡
3. 在系统设置里把文字转语音引擎切成中文（`设置 → 语言和输入法 → 文字转语音输出`）
4. 语速调到 0.9 左右，默认偏快
5. 媒体音量调大 —— 卡片朗读走媒体通道。设置页底部有「朗读自检」，点「试听一句」当场验证；
   媒体音量是 0 时它会直接提示，并给一个跳到声音设置的按钮
6. 打开「播放提示音」，先响一声再亮卡片，隔房间或背对时有用
7. **朗读默认是开的**：点开卡片就自动念出来。想安静时去设置里关掉；关掉之后卡片左下角还有喇叭按钮，点一下念一次
8. App 会按系统语言自动选中文音色矫正一次，语速固定 0.9；如果念出来仍是拼读，说明系统没装中文语音包，回第 3 步

## 测试

```bash
./gradlew :app:testDebugUnitTest    # 54 用例
```

- `PresetCardsTest` — 预置数据自洽（分类 id、数量、索引、字号、收藏）
- `PresetSeederTest` — Robolectric + 真实 Room SQLite，验证首启写入、幂等、删光不回灌
- `RecoveryTimelineTest` — 术后天数换算、阶段边界连续不重叠、任意天数都能落段
- `CardFilterTest` — 全部 / 收藏 / 分组三种筛选，含空分组与优先级
- `PageNavTest` — 底部切页：相邻滑动、跨页瞬移
- `ColdPackTimerTest` — 敷/停 20 分钟交替、倒计时边界、时间格式
- `ListViewModelTest` — 上游原有
