# NeedCards

基于 [Aucards](https://github.com/vadimerenkov/Aucards) 的中文预设分支。

**场景**：拔智齿、口腔手术、嗓子术后等短期说不了话，但手能打字的时候。
打开应用就有 34 张写好的中文卡片，点一下就全屏显示并朗读，不用从零开始建。

原版是给自闭症 / ADHD 人群做辅助沟通用的，功能完全够，但首次打开是空列表，
而且没有中文界面。这个分支只做三件事：

1. 内置 34 张中文预设卡片，覆盖「先说一句 / 疼与求助 / 医护 / 日常需求 / 客套 / 应付外人」六类
2. 补全简体中文界面（原版只有英、俄、乌、格、波、葡、法、西八种）
3. 换 `applicationId` 和名称，可与原版同时安装
4. 列表页底部加了「临时说一句」输入条，打完回车直接全屏朗读，不用先建卡

## 临时说一句

预置卡片覆盖不了所有情况。想说一句没写进卡里的话时，不用去建卡：

- 列表页底部输入条打字，回车（或点纸飞机）→ 立刻全屏大字 + 朗读
- 这一屏不落库，退出就没了；想留就点右下角「存为卡片」
- 左下角喇叭可以再念一遍

## 预设内容

| 分类 | 张数 | 例子 |
|---|---|---|
| 先说一句 | 3 | 我说不了话 / 我听得见 / 请等一下 |
| 疼与求助 | 7 | 很疼 / 疼得受不了 / 还在出血 |
| 医护 | 7 | 帮我叫医生 / 几号拆线 / 什么时候复诊 |
| 日常需求 | 9 | 想喝水 / 给我冰袋 / 扶我一下 |
| 客套 | 4 | 谢谢 / 等一下 / 我没事 |
| 应付外人 | 4 | 说不了话 / 多少钱 / 放门口就行 |

卡片按用途配色：红=疼、橙=医护、蓝=日常、绿=客套、灰=对外人、紫=开场说明。
疼的时候按颜色找，不用读字。

另有 8 张预置在「收藏」页（列表向右滑一页）：我说不了话 / 很疼 / 帮我叫医生 /
想喝水 / 给我冰袋 / 帮我拿药 / 谢谢 / 等一下。手机上一屏放得下，不用滚动。

预设只在首次启动写入一次，之后随便改随便删，不会覆盖。

## 安装

- 应用名：NeedCards
- 包名：`icu.xyblue135.needcards`
- 最低 Android 8.0（API 26）

APK 见 Releases，或本地自行编译：

```bash
export ANDROID_HOME=/path/to/Android/Sdk
./gradlew :app:assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

编译环境：Gradle 9.7.1 + AGP 9.4.1 + JDK 17，compileSdk 37。

## 首次使用建议

1. 打开就停在「全部」页，向右滑一页是「收藏」，那 8 张是最常用的，先记住这一页
2. 临时想说的话直接在底部输入条打，回车看完退出即可，不建卡
3. 在系统设置里把文字转语音引擎切成中文（`设置 → 语言和输入法 → 文字转语音输出`）
4. 语速调到 0.9 左右，默认偏快
5. 媒体音量调大 —— 卡片朗读走媒体通道
6. 打开「播放提示音」，先响一声再亮卡片，隔房间或背对时有用
7. **朗读默认是开的**：点开卡片就自动念出来。想安静时去设置里关掉；关掉之后卡片左下角还有喇叭按钮，点一下念一次
8. App 会按系统语言自动选中文音色矫正一次，语速固定 0.9；如果念出来仍是拼读，说明系统没装中文语音包，回第 3 步

## 测试

```bash
./gradlew :app:testDebugUnitTest    # 28 用例
```

- `PresetCardsTest` — 预置数据自洽（分类 id、数量、索引、字号、收藏）
- `PresetSeederTest` — Robolectric + 真实 Room SQLite，验证首启写入、幂等、删光不回灌
- `ListViewModelTest` — 上游原有
